# Tower Defense X (TDX) 66 Towers Tracker & Lua Vault

Interactive 6×11 grid tracker and code vault for all 66 towers in Tower Defense X (Roblox).

## Features
- **Brutalist 6×11 Grid**: Instant visual completion status across all 66 towers.
- **Status Color Scheme**:
  - 🔴 **Red**: Not Done
  - 🟡 **Yellow**: In Progress (18 towers currently populated)
  - 🟢 **Green**: Complete
- **Interactive Lua Code Vault**: Inspect, edit, copy, and tab-indent Lua tables & HP stats for each tower.
- **Persistent Storage & Cloud Backup**:
  - Local edits save immediately in browser `localStorage`.
  - **Export Backup**: Download a timestamped `.json` file backup of all 66 towers with custom edits.
  - **Import Backup**: Restore from any saved JSON backup.
  - **Reset Defaults**: Revert back to the default populated state anytime.
